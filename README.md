# git-demo-2

Página estática en HTML, CSS y JavaScript pensada para practicar Git: editar
archivos, guardar cambios y trabajar con ramas.

## Archivos

- `index.html` — estructura de la página (tarjeta con título y contador).
- `style.css` — estilos, colores y disposición.
- `script.js` — contador de clicks y etiqueta de versión.

No hay build ni dependencias: abrí `index.html` en el navegador y listo.
